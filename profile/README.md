# Dragon NaturallySpeaking

Dragon NaturallySpeaking is speech recognition software that converts spoken language into written text. It supports voice dictation, spoken editing commands, vocabulary customization, and document workflows designed to reduce repetitive keyboard input.

## Overview

Dragon NaturallySpeaking allows users to dictate text into compatible applications and control supported functions through spoken commands. Its features vary by edition and release, with professional editions offering additional customization options.

The application can be configured with user vocabulary and speech profiles to support recurring terminology and individual dictation preferences. Voice commands can assist with correcting text, navigating documents, and carrying out supported editing actions.

## Key Features

| Feature | Description |
| --- | --- |
| Speech Recognition | Converts spoken language into written text. |
| Voice Dictation | Supports document creation using spoken input. |
| Spoken Editing | Provides voice commands for supported text editing actions. |
| Vocabulary Tools | Allows users to manage specialized words and phrases. |
| Speech Profiles | Stores user-specific recognition settings. |
| Custom Commands | Professional editions support customized voice actions. |
| Document Navigation | Uses supported commands to move through text. |
| Text Correction | Allows recognized text to be reviewed and corrected. |
| Dictation Workflow | Supports writing in compatible applications. |

## Use Cases

Dragon NaturallySpeaking can assist with correspondence, reports, notes, and other writing-intensive work. Voice dictation is useful when spoken input is more convenient than typing, while vocabulary customization can help with specialized terminology.

The available functions depend on the installed edition, language, microphone configuration, and compatibility with the target application.

## Installation / Setup

1. Confirm which Dragon NaturallySpeaking edition you have and whether it is compatible with your computer.
2. Obtain the installer from a legitimate source for that specific edition.
3. Run the installer and follow the setup instructions.
4. Complete the required activation and user-profile configuration.
5. Connect a compatible microphone and configure audio input.
6. Follow the speech setup process and test dictation in a supported application.
7. Review the available voice commands and vocabulary settings.

Dragon NaturallySpeaking is a legacy product name associated with earlier Dragon speech recognition releases. Compatibility, language support, activation, and available features depend on the specific edition. Check the documentation for the edition you own before installation.
